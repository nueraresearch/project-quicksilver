Agents propose. A kernel authorizes. A different human approves.

Nuera Quicksilver. Every step is recorded in Sanity, and the kernel is plain TypeScript with no model inside.

1. A person asks

One chat. It answers from records and shows what it looked at. For work, it offers a card; nothing runs until the person presses it.

2. Agents propose

Agents read the company through Sanity Context and propose actions. They hold no authority.

3. Engine evaluates

Scores grounding, tool failures, uncertainty and brittleness. It can make a decision stricter, never looser.

4. NQC Kernel authorizes

Capability grants, policy scope, evidence and a 0 to 5 risk score. Answers: allow, needs a human, or block.

5. A different human approves

Bound to the exact action and policy version. Whoever requested or proposed it cannot approve it. Stale approvals are refused (409).

6. Execute and observe

Executes (a simulation in this build), records the outcome and metric, writes it all back to Sanity, and can propose a rollback.

Sanity: the company, and the record

Company model: organization, departments, entities (people, agents, systems), capabilities, policies, objectives, workflows, evidence.

Record: decisions with the kernel's explanation, evaluation records, trace spans, and a downloadable audit trail with a digest.

agents read via Context MCP: live dataset + knowledge base
Layers: Foundation (runtime, triggers, memory, SDKs) · Kernel loop · Intent loop · Playbooks as content. Not shown: durable run queue, host, vault, workflow builder, agent catalog.
